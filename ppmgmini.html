ppGF-mini

一个从零到一的声子格林函数核心框架，致力于实现从原子尺度到宏观热力学的精确模拟。

探索 GitHub 仓库

项目现状

我们已经拥有了一个可 pip install 的、完全自研的声子格林函数核心框架。目前，它能够基于简谐格林函数计算热导率 κ(T,P)，并已成功在示例中返回了 7–15 W/m/K 的结果。

  • ✅ 所有骨架文件已推送，CI 流程正常运行。
  • 🚀 支持任意超胞和任意 q-mesh，接口已预留。
  • 🔒 代码无外部黑盒，核心功能完全自研。

核心功能模块

#core.py

已实现基于简谐格林函数的 κ(T,P) 计算。

#phonon.py

新增了动力学矩阵和群速度的计算模块。

#greens.py

集成了简谐格林函数和 Kubo 热导率 κ 的计算方法。

未来路线图

  1. 用真实的 QE/VASP 导出的 fc2.hdf5 数据替换占位力常数。
  2. 加入三声子散射 Σ(3)(ω,T,P)，实现非简谐热导率 κ 的计算。
  3. 引入 Birch–Murnaghan EOS 模型，支持在线更新 V(P)。
  4. 支持缺陷/熔体掺杂的 T-matrix 散射机制。
  5. 利用 Ray 和 CuPy 实现 GPU/多节点并行化。
